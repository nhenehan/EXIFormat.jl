Options and header

What both ends must agree on, and what the header of a stream holds.

EXIFormat.ExiOptions — Type
ExiOptions(; alignment, compression, strict, fragment, preserve, self_contained,
           value_max_length, value_partition_capacity, block_size, schema_id,
           datatype_representation_map)

The EXI options. schema_id is nothing (absent), SCHEMA_ID_NIL, or a string ("" is the empty schemaId). The two value limits are nothing when unbounded. strict_options gives the profile EXIFormat targets.

Strict options with everything else at its default; keywords change other fields.

EXIFormat.validate_options — Function
validate_options(opts)

Throws for any option EXIFormat does not support (an UnsupportedError) and for combinations the spec forbids (a HeaderError).

source
EXIFormat.with_schema_id — Function
with_schema_id(tables::GrammarSet, id::AbstractString) -> GrammarSet

The same tables (shared, not copied) going by id, which a decoder checks the stream's schemaId against (see check_schema_id). Tables compiled from XSD have no id until given one here.

source
EXIFormat.check_schema_id — Function
check_schema_id(stream, tables)

Checks a stream's schemaId option (nothing, SCHEMA_ID_NIL or a string) against the schemaId of the tables that will decode it (nothing or a string), and throws a SchemaIdError if they do not match:

  • absent (nothing): the schema was agreed out of band; nothing to check.
  • xsi:nil="true" (no schema, built-in grammars): always refused, because EXIFormat's tables are schema-informed.
  • "" (built-in types only) and any other value: the tables' id must be exactly that string. Tables with no id are refused, because a stream that names its schema cannot be checked against tables that do not.

rexi applies the same rule (rexi_core::header::check_schema_id).

source
EXIFormat.SCHEMA_ID_NIL — Constant
SCHEMA_ID_NIL

The schemaId option set to xsi:nil="true" (EXI 5.4): the stream says it was written without a schema.

source
EXIFormat.Alignment — Type
Alignment

How values are laid out in the body (EXI 5.4):

  • ALIGN_BIT_PACKED: packed bit by bit, the smallest form (the default).
  • ALIGN_BYTE_ALIGNED: every event code and value starts on a byte boundary.
  • ALIGN_PRE_COMPRESSION: not supported; refused with an UnsupportedError.
