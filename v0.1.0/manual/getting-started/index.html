Getting started

In this chapter you'll add EXIFormat to a project and run the examples.

Add EXIFormat to your project

EXIFormat needs Julia 1.10 or newer.

using Pkg
Pkg.add("EXIFormat")

To work on EXIFormat itself, clone it and use the clone instead: Pkg.develop(path = "path/to/EXIFormat.jl").

Then:

import EXIFormat

EXIFormat has no exports. You write every name as EXIFormat.name, so it is always clear where a name comes from.

Run the examples

The examples live in examples/basics of the repository, with their own Project.toml. Clone the repository first; the copy that Pkg.add installs is read-only.

git clone https://github.com/nhenehan/EXIFormat.jl && cd EXIFormat.jl
julia --project=examples/basics -e 'using Pkg; Pkg.develop(path=".")'   # once
julia --project=examples/basics examples/basics/roundtrip.jl
julia --project=examples/basics examples/basics/run-all.jl          # every example

The sample order

Every example uses the same two files in examples/basics/data. The schema says an Order has an orderId, a Customer, one or more Items and maybe some Notes:

<?xml version="1.0" encoding="UTF-8"?>
<Order xmlns="urn:rexi:interop:order" orderId="ORD-2026-0007" priority="true">
  <Customer loyaltyId="L-8821">
    <Name>Raven Bookstore</Name>
    <Tier>gold</Tier>
  </Customer>
  <Item sku="BK-001">
    <Description>Distributed Systems Patterns</Description>
    <Quantity>2</Quantity>
    <Price>42.95</Price>
  </Item>
  <Item sku="BK-014">
    <Description>Practical EXI</Description>
    <Quantity>1</Quantity>
    <Price>31.50</Price>
  </Item>
  <Notes>gift-wrap requested</Notes>
</Order>
The schema, `order.xsd`
<?xml version="1.0" encoding="UTF-8"?>
<xs:schema xmlns:xs="http://www.w3.org/2001/XMLSchema"
           targetNamespace="urn:rexi:interop:order"
           xmlns="urn:rexi:interop:order"
           elementFormDefault="qualified"
           attributeFormDefault="unqualified">
  <xs:element name="Order" type="OrderType"/>

  <xs:complexType name="OrderType">
    <xs:sequence>
      <xs:element name="Customer" type="CustomerType"/>
      <xs:element name="Item" type="ItemType" maxOccurs="unbounded"/>
      <xs:element name="Notes" type="xs:string" minOccurs="0"/>
    </xs:sequence>
    <xs:attribute name="orderId" type="xs:string" use="required"/>
    <xs:attribute name="priority" type="xs:boolean" use="optional"/>
  </xs:complexType>

  <xs:complexType name="CustomerType">
    <xs:sequence>
      <xs:element name="Name" type="xs:string"/>
      <xs:element name="Tier" type="xs:string"/>
    </xs:sequence>
    <xs:attribute name="loyaltyId" type="xs:string" use="optional"/>
  </xs:complexType>

  <xs:complexType name="ItemType">
    <xs:sequence>
      <xs:element name="Description" type="xs:string"/>
      <xs:element name="Quantity" type="xs:int"/>
      <xs:element name="Price" type="xs:decimal"/>
    </xs:sequence>
    <xs:attribute name="sku" type="xs:string" use="required"/>
  </xs:complexType>
</xs:schema>
