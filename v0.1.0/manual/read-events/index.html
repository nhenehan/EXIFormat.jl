Reading events

In this chapter you'll read a stream one piece at a time and get typed values, not text.

decode_to_xml is handy, but sometimes you want the data, not the text. The pull decoder hands you one event at a time: the start of an element, an attribute, some content, or the end of an element.

flowchart LR SD([start document]) --> SE1["start Order"] --> AT1["@orderId"] --> AT2["@priority"] AT2 --> SE2["start Customer"] --> more["..."] --> EE["end Order"] --> ED([end document])

A Decoder is an iterator, so a for loop walks the whole document. Each event is a small struct (StartElement, Attribute, Characters, ...), so you can check its kind with isa:

"""The value as text, followed by the kind of value the decoder gave."""
function describe(value)
    kind = value isa AbstractString ? "string" :
           value isa Bool ? "boolean" :
           value isa Integer ? "integer" :
           value isa EXIFormat.ExiDecimal ? "decimal" : "other"
    return "$(EXIFormat.plain_format(value)) ($kind)"
end

tables = EXIFormat.compile_files(data("order.xsd"))
exi = EXIFormat.encode_xml(read(data("order.xml"), String), tables)

dec = EXIFormat.Decoder(exi, tables; options = EXIFormat.strict_options())
depth = 0
# A decoder is also an iterator: the loop ends after the end of the document.
for event in dec
    indent = "  "^depth
    if event isa EXIFormat.StartDocument
        println("start document")
    elseif event isa EXIFormat.EndDocument
        println("end document")
    elseif event isa EXIFormat.StartElement
        println(indent, event.local_name)
        global depth += 1
    elseif event isa EXIFormat.EndElement
        global depth -= 1
    elseif event isa EXIFormat.Attribute
        println(indent, "@", event.local_name, " = ", describe(event.value))
    elseif event isa EXIFormat.Characters
        println(indent, describe(event.value))
    else
        println(indent, EXIFormat.event_name(event))
    end
end

What to notice

  • Values are typed. priority arrives as a Bool and Quantity as an integer. You don't have to parse text, because the schema already said what each one is.
  • Events are yours to keep. Each event is a plain value. You can push it into a vector or pass it to EXIFormat.Encoder later.
  • next_event! works too. To pull events one by one yourself, call EXIFormat.next_event!(dec). It gives the next event, or nothing at the end.
