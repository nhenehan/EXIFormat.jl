EXIFormat.jl

EXIFormat turns XML into small, fast binary messages and back, in Julia. This manual shows you how, one small example at a time.

EXI (Efficient XML Interchange) is a W3C standard for sending XML as compact binary. The order in this guide's examples is 538 bytes of XML and only 129 bytes of EXI.

The trick is that both sides share the XML schema. Each side knows which elements and attributes can come next, and what type each value has. So the stream does not have to spell out names or write numbers as text.

flowchart LR xsd[order.xsd] --> tables[Grammar tables] xml[order.xml] --> enc[Encoder] tables --> enc enc --> exi[(EXI bytes)] exi --> dec[Decoder] tables --> dec dec --> out[XML, events or structs]

New to EXI? Words you'll see explains the terms in one or two lines each.

Installation

EXIFormat needs Julia 1.10 or newer. In the Pkg REPL (press ]):

pkg> add EXIFormat

or with using Pkg; Pkg.add("EXIFormat").

Quick start

tables = EXIFormat.compile_files(data("order.xsd"))   # once
xml = read(data("order.xml"), String)
options = EXIFormat.strict_options()
exi = EXIFormat.encode_xml(xml, tables; options)
back = EXIFormat.decode_to_xml(exi, tables; options)
println(sizeof(xml), " bytes of XML became ", length(exi), " bytes of EXI")
538 bytes of XML became 129 bytes of EXI

What you will learn

Each chapter of the manual follows one small script in examples/basics, from easiest to hardest:

  1. Round trip: XML to EXI and back in three calls.
  2. Options: what the header holds, and what changes the size.
  3. Reading events: walking a stream one piece at a time.
  4. Writing events: building a document without any XML text.
  5. Structs: turning your own Julia types into EXI.
  6. Prebuilt tables: skipping the schema step when your program runs.

Every example has a Rust twin in rexi that prints exactly the same output, so you can read the two languages side by side.

What EXIFormat does not do (yet)

EXIFormat works in strict, schema-informed mode only. That is the most compact form EXI offers. Compression, schema-less streams, non-strict mode, the "preserve" options (comments, prefixes and so on), wildcards (xs:any, xs:anyAttribute) and fragments are refused with a clear error. EXIFormat never quietly does something close enough instead.
