EXIFormat and rexi side by side

This page helps you move between EXIFormat and rexi, its Rust twin.

Each example in examples/basics (in EXIFormat.jl) has a twin in rexi/examples/basics that prints exactly the same output. rexi's examples/basics/compare.sh runs both and checks.

TaskEXIFormat (Julia)rexi (Rust)
Compile a schemaEXIFormat.compile_files(path)rexi_schema::compile_files(&[path])
Strict optionsEXIFormat.strict_options()ExiOptions::strict()
Change an optionstrict_options(; alignment = EXIFormat.ALIGN_BYTE_ALIGNED).with_alignment(Alignment::ByteAligned)
Header settingsHeaderConfig(; cookie = true, include_options = true)HeaderConfig::new().with_cookie(true).with_include_options(true)
XML to EXIEXIFormat.encode_xml(xml, tables; options, header)rexi_xml::encode_xml(xml.as_bytes(), tables, opts, header)
EXI to XMLEXIFormat.decode_to_xml(bytes, tables; options)rexi_xml::decode_to_xml(bytes, tables, Some(opts))
Read eventsfor ev in decwhile let Some(ev) = dec.next_event()?
Write eventsEXIFormat.start_element!(enc, ns, name)enc.start_element(ns, name)?
Text to parseEXIFormat.Lexical("42.95")Value::Lexical("42.95")
StructsEXIFormat.to_exi / from_exi with exi_namesrexi_serde::to_exi / from_exi with serde
Prebuilt tablesEXIFormat.SchemaGen.generaterexi-schema-gen command
ErrorsExceptions such as UnsupportedErrorResult with ExiError

rexi also has things EXIFormat does not: no_std and fixed buffers for small devices, streaming from any Read/Write, a C API, and (since rexi 0.3) schema-informed fragments.
