XML text

Go straight between XML text and EXI bytes.

EXIFormat.encode_xml — Function
encode_xml(xml, tables; options = strict_options(), header = HeaderConfig()) -> Vector{UInt8}

Encodes an XML document as EXI with the grammar tables of its schema.

source
EXIFormat.decode_to_xml — Function
decode_to_xml(bytes, tables; options = nothing, limits = DecodeLimits()) -> String

Decodes a stream to an XML document. limits caps what a hostile stream can ask for (see DecodeLimits).

source
EXIFormat.xml_events — Function
xml_events(xml) -> Vector{Event}

The events of an XML document, from SD to ED, with Lexical values.

source
EXIFormat.decode_events — Function
decode_events(bytes, tables; options = nothing, typed = false, limits = DecodeLimits()) -> Vector{Event}

Decodes a stream into events. Values are given in their standard text form (the datatype's canonical form), or as typed values with typed = true. limits caps what a hostile stream can ask for (see DecodeLimits).
