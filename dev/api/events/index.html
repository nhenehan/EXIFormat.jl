Events

Read a stream one event at a time with a Decoder, or write one with an Encoder.

EXIFormat.Decoder — Type
Decoder(bytes, tables; options = nothing, limits = DecodeLimits())

A decoder for one stream over the grammar tables tables. options are the options agreed out of band; they are needed when the header carries none. The options' schemaId must name tables (see check_schema_id). limits caps what a hostile stream can make the decoder do; going over a cap throws a LimitError (see DecodeLimits).

EXIFormat.Encoder — Type
Encoder(tables, options = strict_options(); header = HeaderConfig())

An encoder for one stream, over the grammar tables tables (a GrammarSet). It writes the header (and the options document when header.include_options) right away.

EXIFormat.xsi_type! — Function
xsi_type!(enc, uri, local)

Writes xsi:type: the escape codes, then the type's QName through the string table, and switches the element to that type's grammar. A name that is not a type in the schema is written all the same, and the element keeps its grammar (https://www.w3.org/TR/exi/#addingProductionsStrict switches only to a type that exists); EXIficient does the same. As in EXIficient, the target type's own grammar is used, which has no escapes left (https://github.com/EXIficient/exificient-grammars/blob/9baa044237f649a65ae4190aed75081c75c86a16/src/main/java/com/siemens/ct/exi/grammars/XSDGrammarsBuilder.java#L1474-L1499).

EXIFormat.finish! — Function
finish!(w) -> Vector{UInt8}

Pads the last byte with zeros and returns the bytes written.

source
finish!(enc) -> Vector{UInt8}

The encoded bytes, with the last byte padded. The document must be complete. The vector is the encoder's own buffer: after reset! the encoder writes the next stream into it, so copy what you need to keep first.

source
EXIFormat.reset! — Function
reset!(dec::Decoder{V}, bytes::V) -> dec

Points dec at the next stream, bytes (of the same type as before), and makes it behave as a new Decoder over those bytes with the arguments it was built with: same tables, out-of-band options and limits. A header that carries options applies to this stream only. Buffers are kept.

source
reset!(enc::Encoder) -> enc

Starts the next stream: enc behaves as a new Encoder built with the same arguments, and writes the header again. Buffers are kept, including the one finish! returned, which the next stream overwrites.

source
