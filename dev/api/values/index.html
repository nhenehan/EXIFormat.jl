Values

Typed values in events. Pass a Lexical to have EXIFormat parse text with the schema's type.

EXIFormat.Lexical — Type
Lexical(text)

A value in its XML text form (XML Schema calls it the "lexical" form). The grammar's datatype decides how it is parsed.

source
EXIFormat.TextValue — Type

A decoded value with its standard text form.

source
EXIFormat.ExiDecimal — Type
ExiDecimal(negative, integral, fraction_reversed)

A decimal (EXI 7.1.3): sign, the whole-number part, and the digits after the point in reverse order, as an integer. So .05 is stored as 50 and .50 as 5 (trailing zeros cannot be stored). Zero is never negative.

source
EXIFormat.ExiFloat — Type
ExiFloat(mantissa, exponent)

A float (EXI 7.1.4): mantissa * 10^exponent. The exponent -16384 marks the special values: mantissa 1 is +INF, -1 is -INF, and anything else is NaN.

source
EXIFormat.ExiDateTime — Type
ExiDateTime(kind; year, month, day, hour, minute, second, fractional_secs, timezone)

A date/time value (EXI 7.1.8). Which fields mean anything depends on kind. fractional_secs holds the digits after the point reversed (.5 is 5, .05 is 50); timezone is the offset from UTC in minutes. Both are nothing when absent.

source
EXIFormat.ExiList — Type
ExiList(items)

The items of a List value (EXI 7.1.11).

source
EXIFormat.ExiUint — Type

An unsigned integer of any size: UInt64 when it fits, else BigInt.
