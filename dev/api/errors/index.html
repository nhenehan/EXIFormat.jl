Errors and limits

Every error is an ExiError. Decoder limits stop hostile streams early.

EXIFormat.ExiError — Type
ExiError

The parent type of every failure EXIFormat reports.

source
EXIFormat.UnsupportedError — Type

A feature documented as not supported, on purpose, was asked for or found.

source
EXIFormat.Feature — Type
Feature

An EXI feature EXIFormat does not implement, on purpose. When one of these shows up it is always reported as an [UnsupportedError]; it is never quietly ignored.

source
EXIFormat.LimitError — Type
LimitError(limit, max)

The stream went over one of the [DecodeLimits]. limit is :depth, :list_items, :integer_bits or :string_bytes, and max is the cap that was set. Raise the cap (or turn it off) only if you trust the input.

source
EXIFormat.DecodeLimits — Type
DecodeLimits(; max_depth = 256, max_list_items = 1_000_000,
               max_integer_bits = 4096, max_string_bytes = 256 * 1024 * 1024)

Caps on what one decoded stream may ask for. EXI packs a lot into few bytes, so a small hostile stream can otherwise make the decoder run out of memory, spend minutes on one number, or overflow the stack. When a stream goes over a cap, the decoder throws a [LimitError] and stops.

  • max_depth: elements open at once. Stops endless self-nesting and very deep trees (which would also overflow the stack in from_exi).
  • max_list_items: items in one list value. Stops a short stream that claims a list of billions of zero-size items.
  • max_integer_bits: bits in one integer (also the parts of decimals, floats and years). Reading a huge integer takes time that grows fast with its size.
  • max_string_bytes: total UTF-8 bytes of all string values in the stream. A string-table hit repeats a long string for a few bits, so this stops a small stream from growing into gigabytes of text.

nothing turns a cap off; [unlimited_limits] turns them all off. The defaults are far above what normal documents need. Pass limits with the limits keyword of Decoder, decode_events, decode_to_xml and from_exi, or with the --max-* and --no-limits flags of the exiformat tool:

limits = EXIFormat.DecodeLimits(max_depth = 1000)
xml = EXIFormat.decode_to_xml(bytes, tables; options, limits)
source
EXIFormat.unlimited_limits — Function
unlimited_limits() -> DecodeLimits

Limits with every cap turned off. Use this only for input you trust.

EXIFormat.SchemaIdError — Type
SchemaIdError(stream, tables)

The stream's schemaId option does not name the schema of the grammar tables it is decoded with (https://www.w3.org/TR/exi/#key-schemaIdOption). stream is what the options say (SCHEMA_ID_NIL or a string), and tables the tables' own id (nothing if they have none). See check_schema_id.
