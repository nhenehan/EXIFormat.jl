Prebuilt tables

In this chapter you'll compile the schema ahead of time and save the tables as Julia code, so your program starts fast.

Up to now, every script read and compiled order.xsd when it started. You can do that work once and save the grammar tables:

import EXIFormat
EXIFormat.SchemaGen.generate(["examples/basics/data/order.xsd"];
    out = "examples/basics/order_tables.jl", module_name = "OrderTables")
flowchart LR subgraph "Ahead of time" X[order.xsd] --> G[EXIFormat.SchemaGen] --> R[order_tables.jl] end subgraph "When your program runs" R --> S["OrderTables.GRAMMARS"] --> E[Encoder / Decoder] end

The result is a module with a constant GRAMMARS. Use it anywhere you used compiled tables:

xml = read(data("order.xml"), String)
options = EXIFormat.strict_options()

# Timings vary from run to run, so they go to stderr; stdout stays the same on
# every run.
t = @elapsed compiled = EXIFormat.compile_files(data("order.xsd"))
println(stderr, "compiling the XSD took ", round(t * 1e6; digits = 1), "µs")

prebuilt = OrderTables.GRAMMARS
a = EXIFormat.encode_xml(xml, compiled; options)
b = EXIFormat.encode_xml(xml, prebuilt; options)
println("EXI: ", length(b), " bytes")
println("same bytes with compiled and prebuilt tables: ", a == b)

back = EXIFormat.decode_to_xml(b, prebuilt; options)
first_tag = first(split(back, '>'))
println("decoded with prebuilt tables: ", first_tag, ">...")
compiling the XSD took 505.8µs
EXI: 129 bytes
same bytes with compiled and prebuilt tables: true
decoded with prebuilt tables: <Order xmlns="urn:rexi:interop:order" orderId="ORD-2026-0007" priority="true">...

Why bother?

  • No start-up cost. Include the file in your package and the tables are precompiled with it.
  • No XSD files to ship. The schema is built into your code.
  • Fast names. The module also has a constant for every name, such as OrderTables.LN_ORDER. EXIFormat.start_element!(enc, OrderTables.LN_ORDER) skips the name lookup.

In your tests, pass check = true to generate. It returns false if the file no longer matches the schema.
