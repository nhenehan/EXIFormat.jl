Your first round trip

In this chapter you'll turn XML text into EXI bytes and back again. It takes three steps:

flowchart LR A["compile_files(order.xsd)"] --> T[tables] T --> B["encode_xml(xml, tables)"] B --> E[(129 bytes)] E --> C["decode_to_xml(bytes, tables)"] T --> C
# Turn the schema into grammar tables. This is the slow step, so do it once and
# reuse the tables for every document.
tables = EXIFormat.compile_files(data("order.xsd"))

xml = read(data("order.xml"), String)
# Strict and bit-packed, with the options agreed outside the stream: the smallest
# output, with a header of a single byte.
options = EXIFormat.strict_options()
exi = EXIFormat.encode_xml(xml, tables; options)

println("XML: ", sizeof(xml), " bytes")
println("EXI: ", length(exi), " bytes")
print(hex_lines(exi))

# The stream does not say which options it used, so the decoder is told.
# Values come back in their standard text form, so "31.50" turns into "31.5".
back = EXIFormat.decode_to_xml(exi, tables; options)
println("decoded XML:")
println(back)

What to notice

  • Compile the schema once. compile_files makes the grammar tables. It is the slowest step, so keep the tables and reuse them for every document.
  • The decoder needs the same options. Here the options are not written into the stream (that keeps it small), so decode_to_xml is told them. The next chapter shows the other way.
  • Values come back in standard form. The price 31.50 comes back as 31.5, because EXI stores the number, not the text you typed. The line breaks between elements are dropped too. The schema says those elements hold only other elements, not text.
